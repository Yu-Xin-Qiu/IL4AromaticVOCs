# Deep Learning Driven Ionic Liquid Screening for Aromatic VOCs Capture Enhanced by Transfer Learning
This is the official implementation of "Deep Learning Driven Ionic Liquid Screening for Aromatic VOCs Capture Enhanced by Transfer Learning".In this work, advanced deep learning (DL) models are developed to predict the infinite dilution activity coefficients (γ∞) of IL-toluene/styrene systems, which could act as the thermodynamic estimator of absorbent performance. By leveraging the transfer learning strategy, the models are first pre-trained on 1.4 million computational data points, then fine-tuned using 1,586 experimental data points to improve predictive performance. A multi-level screening framework considering physical, thermodynamic, and EHS properties screening is employed to identify favorable ILs from 170 commercially available candidates. Experimental validation and mechanism analysis are conducted to corroborate the excellent absorption performance of screened ILs. This research provides guidance for DL modeling for small dataset and rational design of absorbents for other VOCs capture.
